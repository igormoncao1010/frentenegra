# Frente Negra Brasileira

Site estático e leve, desenvolvido somente com HTML, CSS e JavaScript.

## Estrutura

- `index.html` — conteúdo e metadados
- `styles.css` — identidade visual e responsividade
- `script.js` — menu móvel e animações progressivas
- `assets/` — imagens locais otimizadas em WebP

Para visualizar, abra `index.html` em qualquer navegador moderno.
